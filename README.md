## Запуск

Node.js 24+, зависимости не нужны:

```
npm start
npm test
```

По умолчанию http://127.0.0.1:4173, бронирование отключено. SQLite создаётся в `data/` и исключена из Git. `dist/` — статическая версия для GitHub Pages; она не может сохранять общие бронирования. На Pages календарь показывает состояние отсутствующего серверного подключения, отправка данных заблокирована. `admin.html` и `appointment.html` предназначены для серверного варианта.

## Серверная запись

Запросы доступны с текущего дня по времени Казахстана (UTC+5), на 90 дней вперёд. Один запрос занимает два часа. Варианты начала 10:00, 12:00, 14:00, 16:00 являются предложениями для согласования, **не подтверждённым графиком врача**. Город выбирается пользователем; время блокируется сразу в обоих городах, так как врач один. Реальный график и переезды должны быть согласованы перед запуском.

Сервер резервирует время при отправке запроса на 24 часа. Уникальный индекс SQLite запрещает две активные заявки на один слот. Врач одобряет или отклоняет в `/admin.html`; без одобрения приём не подтверждён. При отказе, отмене либо истечении 24 часов время освобождается. Состояние обновляется у клиентов каждые 30 секунд и перед созданием новой заявки. Прошедшее время недоступно. Клиент получает секретную ссылку для проверки статуса и отмены; в базе хранится только хеш токена.

Публичный API отдаёт только время и доступность. Имя и телефон доступны только серверному администратору. Административный ключ не сохраняется в браузере или репозитории. Автоматической отправки SMS/WhatsApp/email нет: администратор должен открыть панель и при необходимости связаться с человеком сам. Контакты очищаются спустя 30 дней после даты визита.

Для реального запуска нужен постоянно доступный сервер Node 24+ с HTTPS, постоянным диском, резервным копированием и контролем доступа. Задайте через секретные переменные окружения хостинга: `ADMIN_TOKEN` (случайный длинный ключ), `BOOKING_ENABLED=1`, `PRIVACY_READY=1`. До этого заполните политику обработки данных реквизитами оператора и согласуйте график. `DATA_DIR` задаёт постоянный каталог SQLite, `HOST=0.0.0.0` и `PORT` — сетевой адрес. Не включайте реальную запись на демонстрационном сайте без согласия врача.

Рекомендуется размещать весь сайт на том же сервере. При отдельном frontend настройте `ALLOWED_ORIGIN` и meta `booking-api`; страницы статуса и администратора должны использовать соответствующий серверный адрес. Для публичного запуска добавьте CAPTCHA и внешний rate limit, уведомления и расписание по городам. Встроенное ограничение запросов по IP — базовая защита, оно сбрасывается при перезапуске.
